Grok review: request changes (one item). Nearly all of this is right: the popup-close effect correctly keeps the newly opened popup when a marker is clicked, Back keeps the selection per Brian's decision, the 44px button and the marker focus ring are good, and the tests pass. One accessibility problem: `flex-direction: column-reverse` makes the desktop visual order (map above details) differ from the DOM and Tab order (details before map). That fails WCAG 2.4.3 Focus Order / 1.3.2 Meaningful Sequence; a keyboard user on details who presses Tab jumps up the screen into the map. Fix: put the DOM order as list, map, details and drop the column-reverse. That matches the desktop visual order. On phone the single column becomes list, map, details. That's acceptable because selecting a park already focuses the details heading and scrolls it into view, which was the actual phone complaint. Minor: use behavior 'auto' instead of 'instant' in scrollIntoView (same effect, wider support). Please also check the marker focus outline isn't clipped by Leaflet's overflow; if it is, drop outline-offset to 0 or use a negative offset.
